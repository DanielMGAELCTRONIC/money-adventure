# Money Adventure

A British money learning game with eight levels, familiar coin photographs,
exact-payment shopping and change from £1, £5 and £10.

## Publish with GitHub Pages (free)

1. Create a public repository named money-adventure on a free GitHub account.
2. Upload index.html and .nojekyll from this folder to the repository root.
3. In Settings > Pages, choose Deploy from a branch, main, and / (root), then Save.
4. Use the website address shown in Pages once publishing finishes.

Open that website address in Safari on iPhone. You can email the address to
someone else. The HTML attachment itself will not open as a normal website
in Apple Mail or Files.

The images and game code are embedded in index.html; no build is needed.
Progress is stored in each browser and is not shared between devices.
The game and uploaded files are public when hosted with this free setup.

Image credits and source links are included within the game.
